# Джара (Djara)

Russian-first, Greek-themed rebrand of [nesquena/hermes-webui](https://github.com/nesquena/hermes-webui).

- Brand: Джара
- Domain: dzhara.ru
- Default UI language: Russian
- Visual identity: omega (Ω) + Mediterranean blue + warm gold
- Audience: non-technical users

Upstream remote: `upstream` -> `nesquena/hermes-webui`. Pull from upstream and merge into the `djara` branch to track new releases.
